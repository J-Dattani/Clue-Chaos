# Clue Chaos - A Thrilling Social Deduction Game

Welcome to the **Clue Chaos** project repository! This game was developed as a fun and engaging social deduction experience, where players must use their wit and observation skills to identify the undercover and Mr. White.

## About the Project  
**Clue Chaos** is a multiplayer game that challenges players to think critically and communicate effectively. The game is designed to be enjoyed in both guest and login modes, with the latter allowing players to track their past records.  

## How to Play  
1. **Setup:** Players first enter the number of participants (minimum 4) and assign names to each player.  
2. **Card Distribution:** Every player receives a secret word on their card—except:  
   - One player, the **Undercover**, gets a different word without knowing it.  
   - One player, **Mr. White**, gets no word at all.  
3. **Discussion Round:** Players describe their words without revealing them directly. The undercover and Mr. White must blend in and deduce the real word.  
4. **Elimination Round:** Players discuss and vote on who they suspect as the undercover.  
   - If the undercover is eliminated, they lose.  
   - If Mr. White is caught, they get a final chance to guess the real word. If correct, they win and earn the highest points; if wrong, they lose points.  
5. **Game Modes:**  
   - **Guest Mode:** Play without saving records.  
   - **Login Mode:** View and track past game history.  

## Features Developed  
- **Multiplayer Setup:** Dynamic player input with customizable names.  
- **Secret Role Assignment:** Randomized word distribution for Undercover and Mr. White.  
- **Discussion & Elimination Mechanics:** Players engage in a social deduction phase.  
- **Scoring System:** Earn or lose points based on game outcomes.  
- **Guest & Login Modes:** Track progress in login mode or play casually in guest mode.  

## Technologies Used  
- **HTML5**: For structuring the game interface.  
- **CSS (Bootstrap)**: To enhance design and responsiveness.  
- **JavaScript**: For interactive and dynamic gameplay elements.  
- **PHP**: For backend functionality and managing game records.  

## How to Run Locally  
1. Clone the repository:
   ```bash
   git clone https://github.com/J-Dattani/Clue-Chaos
   ```
2. Navigate to the project directory:
   ```bash
   cd clue_chaos
   ```
3. Start a local server (for PHP):
   ```bash
   php -S localhost:8000
   ```
4. Open `http://localhost:8000` in your browser to start playing.
